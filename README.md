# 📊 Calculation Module — Модуль расчёта показателей

Учебный проект: модуль расчёта показателей прикладной системы  
Реализован в рамках ПМ.01 «Разработка модулей программного обеспечения для компьютерных систем».

Проект представляет собой веб-приложение с фронтендом и бэкендом,  
которое принимает входные данные, выполняет расчёты и выводит итоговые показатели.

---

## 🎯 Назначение проекта

Модуль предназначен для:

- приёма входных данных из формы или файла;
- обработки и проверки корректности данных;
- расчёта итоговых показателей;
- отображения результатов пользователю.

Модуль реализован по модульному принципу и может быть использован повторно
в других программных системах.

---

## 🧩 Используемые технологии

- Python 3.11+
- Flask (веб-фреймворк)
- HTML / CSS (пользовательский интерфейс)
- JSON (формат входных данных)
